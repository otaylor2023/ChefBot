
TRIGGER TOOLS
- Some tools work by squeezing while you hold them. An egg cracker with an egg in it cracks
  the egg into whatever it is lowered over (put the egg in the cracker first: place(egg_cracker)
  while holding the egg); cracking leaves the eggshell in the cracker: empty it before the next
  egg (pick up the cracker and pour the shell into the trash can or a spare bowl, never into the
  food). An electric whisk runs only while you squeeze and stops on release().
- release() lets go of the trigger, not the tool; place puts the tool down.
- Release a running whisk before lifting it out (lift_out(), or driving off, which lifts it
  out): a running whisk splatters everything when it comes out of the bowl.
